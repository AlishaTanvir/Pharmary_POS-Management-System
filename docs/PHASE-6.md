## First increment

Migration 008 and the Pilot rollout screen introduce a branch-scoped checklist for pharmacy/profile policy, catalog/pack review, opening-stock reconciliation, staff permissions, counter training, physical peripherals, off-device recovery and deployment security.

The screen shows factual setup counts separately from acceptance declarations. Organization administrators can read/export the selected branch's checklist. An organization administrator acting as branch OWNER must re-authenticate to append evidence. The available states are PENDING, DEFERRED and ATTESTED; ATTESTED is explicitly a named operator declaration, not software certification. Every entry requires evidence/reason text. Existing events cannot be updated or deleted, and an increasing database sequence determines the latest event. Recording another state preserves prior history.

The audited JSON export includes the branch, generated timestamp, factual counts, latest states, history and `production_approved: false`. The user-directed project deferral for printer/scanner and off-device recovery is displayed separately; it never manufactures a branch-level attestation or verified hardware result. Cashiers cannot access the tracker or its recording/export routes.
